# User Flow: Registration & Identity Verification

## Overview
Guides first-time users from app installation through mobile OTP verification to authenticated account creation and onboarding.

## Steps
1. **Welcome Screen** (`credbuddha-onboarding-welcome-default-01.jpg`): Displays value proposition, terms agreement link, and 'Get Started' action.
2. **Phone Number Sign-In** (`credbuddha-auth-phone-signin-default-01.jpg`): User enters 10-digit mobile number and accepts privacy policy.
3. **SMS OTP Verification** (`credbuddha-auth-otp-verification-default-02.jpg`): 6-digit auto-read OTP input with 30s resend countdown timer.
4. **Account Details Form** (`credbuddha-registration-form-default-01.jpg`): User enters full legal name, date of birth, and email address.
5. **Success Confirmation** (`credbuddha-registration-success-confirmed-02.jpg`): Modal confirmation celebrating verified profile and routing to Discovery feed.
